ARGENTINA WORLD STORE — PÁGINA PRINCIPAL

1. Abrí index.html con Google Chrome.
2. Para cambiar el logo:
   - Reemplazá el bloque .logo-placeholder del index.html por:
     <img src="assets/logo.png" alt="Argentina World Store">
   - Copiá tu logo dentro de la carpeta assets.
3. Las imágenes principales ya quedaron guardadas como:
   - Africa.jpeg
   - Asia.jpeg
   - Inglaterra.jpeg
   - Francia.jpeg
   - Oceania.jpeg
4. El selector incluye países de América, Europa, Asia y Oceanía.
5. La traducción está integrada para varios idiomas. Los países sin traducción propia usan inglés.
6. Las cards actualmente usan las imágenes proporcionadas como diseño provisional.
7. Próximo paso recomendado: crear páginas individuales para cada subcategoría y conectar un carrito real.

INTEGRACIÓN DE PAGOS (MERCADO PAGO + PAYPAL)
============================================
- Argentina (código de país AR): Mercado Pago Checkout Pro en pesos argentinos.
- Cualquier otro país: PayPal Business mediante Orders API v2.
- Los secretos se guardan únicamente en el servidor, dentro del archivo .env.
- No abras index.html con doble clic para cobrar. La tienda debe ejecutarse con Node.js.

PASOS PARA PROBAR
1. Instalá Node.js 18 o superior.
2. Copiá .env.example como .env.
3. Colocá tus credenciales de prueba de Mercado Pago y PayPal.
4. Ejecutá: npm install
5. Ejecutá: npm start
6. Abrí http://localhost:3000

PARA PRODUCCIÓN
- Cambiá APP_BASE_URL por tu dominio HTTPS.
- Usá credenciales de producción.
- Configurá y validá webhooks antes de entregar productos.
